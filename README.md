# Neon Bay

Neon Bay is a sunny, top-down open-world crime game starring Sol Vega. Explore the city, drive its streets, evade the police, and complete The Sol Vega Files.

Run `node serve.ts` with Node 22 and open http://localhost:8080. Run `node main.ts` to build the submission dossier.

Move with WASD or the arrow keys. Press E to enter or leave a car, aim with the mouse, click to shoot, and press Space to punch. Press R to reload.
